# Apps

Семейная коллекция браузерных игр и приложений.

- Каталог: https://ridalsultanov.github.io/Apps/
- Мира и Лунный лес: https://ridalsultanov.github.io/Apps/mira/
- Стальной рейд (кооператив на двоих): https://ridalsultanov.github.io/Apps/raid/

Эти адреса доступны после включения GitHub Pages.

## Публикация

В Settings → Pages выберите:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Нажмите Save. Дождитесь завершения публикации (статус можно проверить во вкладке Actions или в Settings → Pages).

## Структура

```text
/
├── index.html       # Каталог приложений
├── .nojekyll        # Статическая публикация без Jekyll
├── README.md
├── mira/
│   └── index.html   # Самостоятельная игра со встроенными ресурсами
└── raid/
    ├── index.html   # Стальной рейд: страница, лобби, сенсорные кнопки
    ├── game.js      # Движок, уровни, боссы, звук, сеть
    ├── peerjs.min.js # PeerJS 1.5.4 для связи двух телефонов
    └── icon.png     # Иконка для экрана «Домой»
```

## Как добавить приложение

1. Создайте отдельную папку с коротким именем латиницей, например `puzzle/`.
2. Поместите стартовую страницу в `puzzle/index.html`, а остальные ресурсы — в эту же папку.
3. Используйте относительные ссылки на ресурсы, например `./styles.css` и `./images/icon.png`. Ссылки вида `/images/icon.png` ведут в корень домена и не учитывают префикс `/Apps/`.
4. В корневой `index.html` добавьте карточку со ссылкой `./puzzle/`.
5. Сохраните изменения в ветке `main`. После публикации приложение будет доступно по адресу `https://ridalsultanov.github.io/Apps/puzzle/`.

Каждое статическое приложение может иметь собственные HTML, CSS, JavaScript и изображения. Отдельный репозиторий не требуется.

## Игра на iPhone

Откройте ссылку игры в Safari. При желании добавьте её через меню «Поделиться» → «На экран Домой».

Сохранение привязано к браузеру и устройству. Очистка данных сайта может удалить прогресс; автоматической синхронизации между устройствами нет. Обычная ссылка требует доступа к интернету для загрузки.

## Обновление Миры

Заменяйте `mira/index.html` актуальной самостоятельной сборкой. Сохраняйте адрес папки и ключи сохранений, если требуется совместимость с существующим прогрессом. После обновления проверяйте запуск, сенсорные кнопки и загрузку сохранения.

## Ограничения хостинга

GitHub Pages публикует статические файлы. Серверный код и приватные ключи здесь не размещаются. Все файлы публичного репозитория открыты для просмотра.
