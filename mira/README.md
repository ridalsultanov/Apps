# Мира — Хранительница Лунолесья

Браузерная игра для Давида. Мира — той-пудель, которая возвращает свет волшебному лесу.

## Играть

Постоянный адрес после включения GitHub Pages: https://ridalsultanov.github.io/Apps/mira/

На iPhone откройте ссылку в Safari. Для отдельной иконки: «Поделиться» → «На экран Домой».

## Что нового

- Глава I: найти три связки досок и восстановить мост.
- Глава II: освободить Пуха и проводить к костру.
- Глава III: зажечь три маяка по порядку.
- Объёмный свет и тени, крупнее Мира, разные фигуры трёх боссов.
- Указатель цели, карточка следующего шага, вступления глав.
- Мягкий режим уменьшает входящий урон на 40%; переключатель тряски и движения деревьев.
- Сохранены три школы магии, магазин, прокачка, шесть друзей и три тайных прохода.
- Старые сохранения версии 1 мигрируют автоматически. Прогресс хранится в браузере устройства.

## Разработка

Исходники лежат в `source/`. `index.html` — сборка с графикой внутри, никаких внешних зависимостей.

Требуется Node.js 20 или новее. Из корня репозитория:

```sh
node mira/build.cjs
node mira/verify.cjs
```

После изменений исходников пересоберите HTML и сохраните обе версии в одном коммите. Для теста в браузере используйте обычный статический HTTP-сервер. Проверка Safari на физическом iPhone пока не выполнена.

## Управление

Телефон: джойстик слева, лай / рывок / действие справа. Атака автоматическая.
Компьютер: WASD или стрелки, E — лай, пробел — рывок, F — действие, P — пауза.
